# M7 자율 행동 및 템포 설계

상태: 사용자 검토용 설계. M7 코드·패키지 설치·훈련은 아직 시작하지 않았다.
기준: feat/core-prototype, M6.2 커밋 7839718. 사용자 M7 요청의 M7.1~M7.4 순서를 유지한다.

## 목적과 보존

느리게 살펴보고, 걷기를 우선하며, 실제 경험으로 행동을 선택하는 클레이 캐릭터를 만든다. 규칙 기반 AI를 삭제하지 않으며 학습 모델이 없거나 추론에 실패하면 Legacy로 복귀한다. 동작 템포 개선과 강화학습 성과를 별도로 평가한다.

M5 타격·드래그, M6 FBX·클립·Animator, Rigidbody·CapsuleCollider, SHORT/LONG 높이, 기존 JSON, 실제 게임의 추락 후 재도전을 보존한다. 기존 두 씬의 레이아웃 및 사용자 미커밋 변경은 수정·덮어쓰기하지 않는다. 초기화와 재배치는 별도 훈련장에서만 허용한다. 외부 유료 추론 API를 사용하지 않는다.

## 확인한 한계

- CharacterMotor의 moveSpeed 기본값은 4, acceleration 24다. MaxJumpHorizontal은 moveSpeed * 1.6이므로 단순 감속은 도달 가능성까지 줄인다.
- Facing은 작은 속도 명령에도 즉시 부호가 바뀐다. ClayAnimator는 540도/초로 회전한다.
- CharacterBrain은 그래프 경로와 점프 파라미터를 선택하지만 Walk/Observe/BackStep 등의 선택을 학습하지 않는다.
- 점프 준비는 inspectDuration .3 + jumpPreparation .18 + 경험별 wait 구조다. 관찰과 실제 준비 표현의 구분이 약하다.
- ClayAnimator 착지 표현은 .18초이고 Brain의 다음 명령과 직접적인 안정화 계약이 없다.
- M6.2가 충돌 기억·궤적 검사·이동 장애물 재계획을 추가했지만 정책 학습을 대체하지는 않는다.

## 접근 방식

권장: 고수준 행동을 PPO 정책이 선택하고, 기존 물리 실행부와 안전 검사는 유지한다. 정책 출력이 실행된 행동, 마스킹/거부된 이유, 결과를 모두 기록한다. 이동량을 매 프레임 신경망에 맡기는 방식보다 기존 회복과 SHORT/LONG 보존에 적합하다.

대안인 연속 힘 제어는 균형·점프까지 재학습해야 하므로 초기 범위를 벗어난다. 기존 규칙에 점수만 더하는 방법은 실제 행동 선택 학습 요구를 충족하지 않아 채택하지 않는다.

## M7.1 — 기존 AI 템포

Inspector에서 조절 가능한 값으로 구성한다. 씬에 이미 저장된 기존 수치를 존중하도록 새 배율/분리 필드를 추가하고, 기존 값의 이름과 의미를 무작정 바꾸지 않는다.

| 항목 | 초기 비교값 | 검증 기준 |
| --- | --- | --- |
| 지상 속도 | 기존의 .70, 기본 4 → 2.8 units/s | 기존 두 씬 통과 및 급가속 감소 |
| 지상 가속/감속 | 8 / 10 units/s² | 출발·정지가 부드럽되 낭떠러지 안전 정지는 우선 |
| 점프 수평 상한 | 기존 6.4 units/s 별도 유지 | SHORT/LONG 도달 범위 감소 없음 |
| 시각 회전 | 150도/초 | 회전 중 이동 속도를 제한해 역방향 미끄러짐 방지 |
| 방향 의도 | 작은 오차 무시, .25초 유지 | 위치 오차로 좌우 반복 회전하지 않음 |
| 준비 동작 | 익숙한 경로 .4초, 새 경로 .65초 | 관찰 시간과 준비 시간을 구분하고 준비 후 실제 도약 |
| 착지 안정화 | .25~.4초 | 실제 안정 접촉 후 재행동, 물리 충격은 즉시 우선 |
| 애니메이션 | Run만 속도와 연동, 상태별 전환 설정 | Sit/GetUp/물리 회복은 원래 타이밍 유지 |

Time.timeScale로 감속하지 않는다. 지상 이동·점프·외부 충격을 구분한다. 점프 준비는 기존 점프 클립의 준비 부분을 사용하되 실제 발사 시점에 공중 부분과 연결하고, 없는 클립을 있다고 가정하지 않는다. 먼저 클립의 구간과 현재 컨트롤러를 조사한다.

단계 통과 조건: 컴파일, 기본 속도/점프 도달 범위 검사, 방향 전환 및 준비·착지 타이밍 측정, Prologue/MainPrototype 실제 목표 도달, 타격·충돌·앉기 회귀 확인. 실패하면 훈련 단계로 넘기지 않는다.

## M7.2 — 단일 제어권과 행동 계약

Perception은 Collider 기반 수치 관찰을 만든다. Policy 인터페이스는 관찰을 받아 행동 의도를 반환한다. 실행기는 그 의도를 기존 Motor/Recovery에 전달한다. Animation은 실행 상태만 표현하고 Memory는 결과만 기록한다.

CharacterBrain의 물리·회복 관찰은 유지하면서 의사결정 진입점에서 Legacy 또는 Learned 중 하나만 선택한다. Learned에서는 Legacy의 Drive/Jump 경로를 실행하지 않는다. 모드 전환은 현재 점프/회복을 안전하게 마친 경계에서 수행하며, 추론 오류 시 새 명령을 멈춘 후 Legacy가 현재 위치에서 재계획한다. 씬 이름이나 특정 발판 좌표를 정책 입력에 넣지 않는다.

행동 공간: Walk, Observe, BackStep, Turn, JumpOver, JumpOnto, Wait. 이동 방향(좌/우), 점프 높이(Short/Long)는 별도 이산 선택이다. 무효 조합과 공중 재점프는 마스킹한다. JumpOver/JumpOnto의 실제 목표 후보와 물리적 유효성은 센서/실행기가 제공하되, 유효한 여러 행동 중 선택은 모델이 담당한다. 정책이 거부된 행동을 반복하는 비율도 평가한다.

관찰은 고정 길이·정규화·버전 관리한다: 목표 상대 방향/거리, 속도, 접지·공중·회복, 지지면 상대 높이/폭, 전방/좌우 여유, 단절 거리, 머리 위 여유, 장애물 상대 bounds/이동 속도, 착지 후보, 최근 행동/성과/충돌/방향/반복 횟수. 없는 관찰은 존재 마스크를 둔다. 월드 절대 위치는 게임 제어에만 쓰고 정책은 상대 정보로 일반화한다.

## M7.3 — 훈련 환경과 보상

별도 AITraining 씬에서 seeded 지형 생성기를 사용한다. 기존 Prologue/MainPrototype은 생성기 입력이나 훈련 씬으로 변경하지 않는다. 초기에는 병렬 소규모 경기장으로 시작하고 성능을 측정해 개수를 조절한다.

Curriculum: 평지 → 낮은 장애물/높은 발판 → 틈과 발판 이동 → 아랫면 회피 → 이동 상자 → 막힌 접근의 대체 경로. 목표 도달률과 불필요 점프율 기준으로 승급한다. 모든 난이도에서 일부 평지 과제를 유지해 걷기 우선 행동의 망각을 감시한다. 경기장별 최대 시간과 낙하 종료는 훈련 전용이다.

초기 보상: 목표 도달 +2, 최초 안전 착지/새 높이 소규모 보상, 목표 거리 감소에 따른 제한된 진행 보상. 불필요 점프 -.05, 장애물 충돌 -.1, 같은 접근 반복은 추가 -.1, 잦은 방향 전환 -.03, 실패 낙하 -.5, 시간 비용 초당 -.005. 왕복으로 진행 보상을 반복 수확하지 못하도록 최고 진행 기록 기준으로 지급한다. 움직이는 상자/타격의 외부 개입은 자기 실패와 구분한다. 보상 크기는 학습 로그와 무행동/점프 남발 빈도로 조정하고 변경마다 새 run ID를 둔다.

초기 PPO는 작은 MLP와 이산 행동으로 시작한다. 실제 학습 단계 수, 환경 seed, 설정, 체크포인트와 ONNX를 기록한다. 짧은 연결 확인 학습은 smoke test로 표기하며 목표 행동 학습 완료로 보고하지 않는다. 모델이 평가 기준을 통과하지 못하면 Legacy를 게임 기본 모드로 유지한다.

### 의존성 조사 결과와 설치 원칙

로컬: Unity 6000.6.0f1, RTX 3060 12GB, Python 3.9/3.8. 현재 manifest에 ML-Agents는 없다.

공식 release_23 소스 확인 결과 Unity package는 4.0.0, 최소 Unity 6000.0, Inference Engine 의존성 2.2.1이다. Python 요구는 >=3.10.1, <=3.10.12이며, 해당 소스의 trainer 버전 표기는 1.2.0.dev0다. 문서의 PyPI 1.1.0 안내와 소스 표기가 다르므로 서로 다른 릴리스를 임의로 섞지 않는다.

설치 후보: Python 3.10.12 전용 환경, 같은 공식 릴리스의 고정 commit에서 C#/mlagents/mlagents_envs를 맞추고 PyTorch 2.2.1 CUDA 12.1을 먼저 시험한다. 정확한 commit, pip freeze, Unity lock 및 CUDA 동작을 기록한다. 이것은 현재 설치/호환성 검증 완료 주장이 아니다. 실제 import, Unity↔Python handshake, 학습, ONNX export, Unity inference까지 통과해야 확정한다. 기존 Python/글로벌 패키지는 교체하지 않는다.

## M7.4 — 미학습 맵 평가

훈련 seed와 평가 seed를 분리하고, 평가 중 가중치·기존 JSON을 업데이트하지 않는다. 5개 지형 유형 × 10개 미사용 seed × 3개 시작 위치를 Legacy/ Learned 양쪽에 동일하게 적용한다. 성공률, 제한 시간 내 도달 시간, 불필요 점프, 반복 충돌, 방향 전환, 상자 이동 후 재개 시간을 CSV로 기록한다. 시간 초과도 실패로 포함하며 성공한 에피소드만 비교하지 않는다.

초기 출시 판정: 평지 불필요 점프율 5% 이하, 미학습 혼합 맵 성공률이 Legacy보다 악화되지 않음, 반복 충돌/불필요 점프 감소, 두 기존 스테이지 회귀 통과. 충족하지 못하면 실험 모델로 보관하고 실패 유형을 보고한다. 자연스러움은 수치와 별도로 실제 화면을 비교한다.

## 산출물과 단계 경계

각 단계는 독립적인 검증 기록과 커밋으로 남긴다. M7.1은 기존 파일의 템포 수정, M7.2는 정책/관찰/실행 계약, M7.3은 훈련 씬·설정·환경 lock·실제 모델, M7.4는 추론 연결과 평가 결과를 제공한다. 큰 체크포인트는 로컬 훈련 폴더에 보존하고 Git에는 필요한 최종 모델 및 재현 설정을 관리한다. 배포 모델이 Git 크기 제한을 넘으면 LFS를 검토한다.

현재 완료: M6.2 보존 및 검증, M7 기존 코드/하드웨어/공식 의존성 조사, 이 설계 작성. 현재 미완료: M7.1 코드부터 모든 M7 실행 단계.
