# M7-D Walking-first Policy Correction Implementation Plan

> Execute incrementally using the existing Unity project and bounded Editor validation bridge. User's detailed M7-D specification authorizes implementation, evaluation and selective commit/push.

**Goal:** preserve the learned model's intent while suppressing unnecessary jumps, approaching feasible takeoff areas and preferring physically feasible SHORT.

**Architecture:** PolicyRoute remains destination/geometry owner. A small per-agent correction object evaluates requested jumps against that route and records local failed attempts. ClimbAgent retains inference, direction, air control, and jump requests; correction neither generates autonomous jumps nor replaces routing. Expose an Inspector switch and evaluation parameter for matched baseline comparisons. Existing turn gates remain authoritative.

**Constraints:** unchanged ONNX, gravity, .8/2.0 scene heights, Rigidbody, map, animations, palm/box inputs, no PPO, no Legacy switch, no gameplay teleport. Preserve all baseline dirty assets (recorded before starting).

**Design decisions:**
- Same-support/walkable target: reject jump and preserve policy horizontal command with floor safety.
- Different target: test current requested launch direction and actual discrete air-control envelope; search safe positions on current support if current pose is unsuitable. Prefer SHORT after approach, not merely because ShortSufficient is true elsewhere.
- Correct approach only within the model's currently requested direction; stop at the feasible window instead of prescribing every movement/air input. Revalidate at takeoff; no jump request means no automatic takeoff.
- Record support/target/mode/location/contact/landing and external interference. Repeated failed local attempts temporarily exclude that location, forcing geometry reevaluation, without disabling Learned.
- Measure physical grounded displacement/time separately from animation state time; headless animation observations are marked unavailable.
