## 관찰과 행동

42개 정규화 관찰: 속도·접지·상대 목표·방향·직전 행동·준비/착지·충돌 시각,
9개 하향 지형 탐침, 좌우 각각 3개 높이의 장애물 탐침, 천장 탐침.
행동은 좌/정지/우 × 점프 없음/SHORT/LONG 두 분기다.
점프 위치나 장애물별 해법을 코드로 지정하지 않는다. 매 결정마다 현재 Collider를 다시 관찰한다.

## 게임 연결과 안전한 복귀

`GameplayPolicyHost`는 기존 Motor/Recovery/Animation을 사용한다.
Learned에서는 CharacterBrain의 물리 업데이트를 끄고, 기존 애니메이션에 상태만 전달한다.
Legacy로 복귀하면 DecisionRequester와 Agent를 끈 뒤 기존 Brain을 재개한다.
모델 누락, 추론 응답 중단, 이중 제어, 8초 동안 목표 방향의 접지 진전이 없을 때 복귀한다.
점프 반복이나 좌우 왕복만으로 감시 시간이 무한 연장되지 않는다. 외부 넘어짐 회복 시간은 제외한다.
목표 위치가 바뀌면 진전 기준을 새 목표로 갱신한다.

Prologue/MainPrototype에 모드 선택 컴포넌트가 연결되며 기본은 Legacy다.
Blue Clay의 GameplayPolicyHost `Starting Mode`를 Learned로 정하면 시작 때 전환한다.
재생 중에는 컴포넌트 메뉴의 Use Learned/Use Legacy 또는 NeverGiveUp / AI Gameplay 메뉴를 사용한다.
테스트 메뉴는 플레이어의 학습 JSON 저장을 끄며, 원본 JSON을 삭제하거나 마이그레이션하지 않는다.

## 한계와 다음 작업 목록

학습 모델은 전체 Prologue를 단독 클리어하지 못했다. 큰 간격에서 발판을 놓치고,
위쪽 목표 바로 아래 바닥에서 작은 좌우 보정만 반복해 Legacy로 복귀한 사례가 있다.
상자 위치 인식은 검증했지만, 플레이어가 만든 모든 계단/상자 퍼즐을 이용한다는 보장은 없다.
임의의 새 지형에 대한 높은 성공률, 장시간 게임 플레이, 성능 프로파일링은 미검증이다.
일반적인 실패는 실제 물리로 남기고, 무응답/무한 정체는 안전한 복귀로 구분한다.

다음 개발은 아래 목록만 제안하며 이번 변경에서 구현하지 않는다.
1. 플레이어 도움이 필요한 짧은 수직 스테이지와 명확한 중간 목표.
2. 기존 상자 이동·손바닥 타격을 활용한 도움/방해의 가독성.
3. 관찰·점프 준비·실패·회복·재도전 애니메이션 전환의 연출 개선.
4. 어려운 지형에서 플레이어가 개입할 시간과 피드백을 조절하는 플레이 테스트.


## 최종 빌드와 추가 회귀

Windows 게임 빌드 성공: `Builds/M7AGame/NeverGiveUp.exe`, 오류 0, 경고 494.
대부분 Inference 패키지의 ConvGeneric 등 GPU 셰이더 변형 경고이며, 사용 정책은 Burst 경로다.
CS0414 및 기존 DEVELOPMENT_BUILD 관련 UAC0009 경고도 남아 있다. 경고 없는 빌드라고 주장하지 않는다.
이 빌드 자체의 별도 장시간 플레이는 수행하지 않았으며 게임 동작 검증은 실제 Editor Play Mode에서 수행했다.

MainPrototype의 Legacy 모드에서 GoalReached/NGU_Idle까지 실제 완주했다.
Learned 모드에서는 초기 구간 이동·점프 후 간격을 놓쳐 추락했고, 회복 뒤 무진전 감시로 Legacy 복귀했다.
이는 복잡한 스테이지 정책 성공의 증거가 아니며 안전한 실패/회복의 증거다.
기존 상자 이동 API 실행도 기록했지만 네이티브 마우스로 상자 드래그하는 전체 입력 경로를 이번에 재검증한 것은 아니다.
