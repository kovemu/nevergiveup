# M8-B 자율 전략·실패 경험 — 구현 및 검증 기록

2026-10-30. 기준 커밋 `c68e85c`, Unity 6000.6.0f1, `feat/core-prototype`.

## 현재 판정

**부분 구현·검증 완료, M8-B 전체 완료 기준은 아직 미충족이다.** 실패 뒤 실제 후퇴·접근 변경, 상자 이동 후 재등반, 물리적 추락 후 재등반은 관찰했다. 그러나 신규 Detour/Offset 지형에서 대체 등반 경로를 끝까지 사용하는 데 실패했고, 사용자가 확장한 OnlyUpMain의 완주도 확인하지 못했다. 이 결과를 우회 성공으로 집계하지 않는다. 기능은 Inspector에서 선택적으로 켜며 기존 씬의 기본값은 변경하지 않았다.

## 구현

- `AutonomousStrategyPlanner`: 주변 최대 8개 발판과 걸어서 접근 가능한 도약 위치를 기존 캡슐 궤적 검사로 평가한다. 실패·진전 없음 이후 대안을 선택하며 실제 PPO가 임시 접근 목표를 따라 움직이게 한다. 같은 지지면 안쪽으로 복귀하는 점프와 제한적인 후퇴도 후보에 포함한다.
- `StrategyExperienceMemory`: 전략 256개, 실제 결과 512개로 제한한 Learned 전용 세션 기록이다. 시간 경과만으로 실패를 지우지 않는다. 성공/실패/중립 개입을 구분하며 시작·도약·착지·충돌·높이·거리·전략 변경 여부를 기록한다.
- `PolicyActionCorrection`은 현재 위치와 **실제 PPO 방향 입력**으로 선택한 점프를 재검사한다. 전략은 좌우 입력을 직접 쓰거나 Rigidbody를 이동시키지 않는다. 단, PPO가 점프를 요청하면 선택한 SHORT/LONG으로 제한하는 보조가 있다. 이를 순수 PPO 운동 선택이라고 주장하지 않는다.
- 42개 관측 형식과 범위를 유지한다. 모델 재학습, ONNX 변경, 점프 높이·중력·속도·모션·손바닥·드래그 변경은 없다.
- 복구 성공 후에도 실패 기억을 유지한다. 다른 발판에 잠시 착지했더라도 같은 전략의 누적 실패가 2회이면 재평가한다. 목표 도달 후에는 새 계획을 만들지 않고 마지막 착지 기록만 마무리한다.
- JSON 입출력과 초기화는 구현했지만, 실제 게임 재실행 간 자동 저장/로드에는 연결하지 않았다. 현재는 세션 기억과 테스트 JSON 내보내기만 사용한다.

## 사용법

1. 캐릭터의 `GameplayPolicyHost`에서 `Correct Policy Actions`를 켠다.
2. `Autonomous Strategy`를 켜면 새 전략 계층, 끄면 기존 M7-D 비교 모드다. Legacy 이동 컨트롤러로 전환하지 않는다.
3. 개발 중 `Show Strategy Debug`로 현재 지지면, 목표, 접근 위치, 후보 수, 원래 PPO 입력, 차단 이유와 경험 값을 확인한다.
4. 컴포넌트 컨텍스트 메뉴의 전략 기억 초기화 기능으로 현재 세션 기록을 지운다. 기존 Legacy 저장 데이터에는 접근하지 않는다.
5. 임의 지형 완주는 보장하지 않는다. 후보가 검증됐다는 것은 해당 가정의 궤적이 가능하다는 뜻이며, PPO가 실제로 그 경로를 실행해 성공했다는 뜻이 아니다.

상자 구조 테스트는 기존 `PhysicsObjectInteraction.Grab/SetTarget`으로 실제 Rigidbody를 끌어 이동했다. 위치 순간이동은 사용하지 않았다. 네이티브 마우스로 상자를 잡는 입력 제스처까지 이 테스트에서 재검증한 것은 아니다. 추락 테스트도 실제 기존 손바닥 타격 API를 호출했다.

Detour/Offset은 낮은 천장과 캡슐 여유 공간 때문에 처음 의도한 도약 위치가 물리 검사에서 거절되는 구간이 있다. 따라서 이 두 실패를 전부 PPO의 문제라고 단정할 수 없다. **충돌이 없는 완전한 우회 경로를 먼저 독립 검증한 새 fixture와, 그 경로의 자율 실행 검증이 남아 있다.** 강제로 모든 후보를 실행하는 컨트롤러로 통과시키지 않았다.

## 검증 범위와 남은 항목

- 경험 기록 9개 검사와 결정적 기록/생명주기 회귀 검사를 실행한다. 후자는 격리된 테스트 상태를 주입하며 실제 정책 자율성 테스트를 대체하지 않는다.
- M7-C 18개, M7-D 22개 기존 검사에서 실패 0을 확인했다. 회전 후 이동·점프, 실제 SHORT/LONG 착지, 정지한 상자와 움직이는 상자의 개입 구분을 포함한다.
- 세션 내 통계 값의 변화는 검증했지만, 성공 경험을 반복 세션/다양한 새 지형에 일반화하는 성능은 검증하지 못했다.
- 대체 경로 발견 비율과 휴식 후 동일 실패 비율의 신뢰할 만한 다회 표본은 아직 없다. 소수의 성공을 보편적 비율로 제시하지 않는다.
- 먼 장애물로 인한 사전 정지 방지는 기존 M7-D 구조적 접근 의도를 유지한다. 기존 전역 그래프 자체를 시야 기반 지도로 재작성하지는 않았다.
- 사용자 씬·모델은 작업 전 SHA256 목록과 비교한다. 원본 사용자 아트/설정/씬의 기존 미커밋 변경은 커밋 대상에서 제외한다.

## 최종 재시험 결과

- `Blocked-on-rescue-20261030-063425.csv`: 상자 이동 시작 32.046초, 목표 도달 43.854초(11.808초 후). 목표 시점 실패 3, 반복 0, 휴식 2, 전략 변경 6/변경 후 성공 2. 75초까지 목표 후 불필요한 시도 기록 증가가 없었다.
