# NeverGiveUp 레벨 에디터 사용법

Unity 메뉴 **NeverGiveUp > Level Editor**를 연다. 창은 Hierarchy 옆에 도킹되며 다른 Unity 탭처럼 위치를 옮길 수 있다. 샘플 씬은 `Assets/_NeverGiveUp/Scenes/OnlyUpMain.unity`이다.

## 기본 작업

1. **OnlyUpMain 열기**를 누른다. 다른 열린 씬에 저장하지 않은 변경이 있으면 먼저 보존한다. **샘플 맵 만들기**는 파일이 아직 없을 때만 새로 생성한다.
2. **Scene 정면**으로 전환하고 현재 구역을 고른다.
3. 팔레트에서 발판·벽·기둥·물리 상자·장식물을 선택한다. **마우스 배치 켜기** 후 Scene을 왼쪽 클릭한다. 격자 간격은 기본 0.25, 0이면 스냅을 끈다.
4. **Esc** 또는 **선택 모드**로 배치를 끝낸다. Scene에서 물체를 선택하고 위치 X/Y, 크기 X/Y를 입력한 뒤 Enter를 누른다. 게임플레이 구조물은 Z=0, 회전=0으로 편집한다. 두께 Z는 프리팹 기본값을 유지한다.
5. **복제 / 삭제 / Undo / Redo** 또는 Unity의 기본 편집 기능을 사용한다. 복제해도 프리팹 연결과 크기 변경이 보존된다.
6. **씬 저장**을 누른다. 별도 맵 파일 포맷 없이 Unity Scene과 프리팹 인스턴스 변경값으로 저장한다.

## 시작·목표와 구역

- 시작·목표 좌표는 캐릭터의 **발 위치** 기준이다. 시작점 변경 시 편집 씬의 캐릭터도 함께 옮겨진다. 목표는 발판 표면에 둔다.
- **구역 추가**로 Terrain 아래 제작 구역을 만든다. **구역 보기**는 해당 구역을 화면에 맞춘다. 구역은 편집 범위이며 게임 중 씬을 분리하거나 비활성화하지 않는다.
- 플레이어가 상자를 옮겨 해결해야 하는 구역은 **플레이어 상자 도움이 필요한 구역**을 체크하고 설계 의도를 적는다. 이 표시는 경로 검사 실패를 성공으로 바꾸지 않는다.
- 새 제작 맵의 발판과 바닥은 직접 편집한 상태를 따른다. 기존 씬의 오래된 자동 바닥 보정은 새 `LevelMap` 씬에 적용하지 않는다.

## 경로 읽기

**전체 검사** 또는 **현재 구역 검사**를 누른다. 기존 PlatformGraph와 PolicyRoute의 SHORT/LONG 캡슐 충돌 검사를 실제 CharacterMotor 설정으로 실행한다.

| 색 | 뜻 |
|---|---|
| 초록 | 걷기 연결 후보 |
| 청록 | SHORT 점프로 통과하는 후보 |
| 주황 | SHORT는 통과하지 못하고 LONG으로 통과하는 후보 |
| 빨강 | 검사한 경로/출발 위치 표본에서 통과하지 못함 |
| 회색 | 검사 전 또는 변경 후 다시 검사해야 함 |

물체를 선택하면 그 물체에 연결된 선만 표시한다. 선택을 해제하면 전체 연결을 본다. 수정 후에는 다시 검사한다. 도달 경로가 없는 발판은 경고에 표시되며, 상자 도움 구역은 별도 문구로 구분된다.

한 번에 128개를 초과하는 Collider가 있으면 구역별로 검사한다. 구역 밖 시작점·목표와 구역 사이 연결은 미검증으로 표시한다. 모든 구역은 플레이 중 하나의 연결된 맵이다.

**물리 경로 후보는 AI 완주 보장이 아니다.** 검사는 제한된 출발 위치 표본을 사용하며, 상자가 움직인 뒤의 경로 또는 모든 가능한 점프를 수학적으로 증명하지 않는다. 빨간 연결도 다른 배치·출발 위치에서는 가능할 수 있다. 반드시 Play로 실제 Learned AI 행동을 확인한다.

## 플레이 확인

**캐릭터 Inspector · Learned 교정 확인**에서 GameplayPolicyHost의 `Correct Policy Actions`가 켜져 있는지 확인한다. 샘플은 M7-D 교정이 켜진 기존 캐릭터 설정을 복사한다. Play 중 레벨 배치는 비활성화된다. 기존 손바닥 타격·상자 드래그와 캐릭터 물리, 학습 모델, 애니메이션은 그대로 사용한다.

샘플은 등반 발판 10개와 안전 바닥·경계·물리 상자 하나로 구성된다. 거대한 최종 맵이 아니라 제작 도구를 시험하는 작은 시작 맵이다.
